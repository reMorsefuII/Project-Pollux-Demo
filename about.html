How do I play/progress?

Each puzzle area has an input box where you can type the code. Alternatively, you can choose to modify the webpage name (index.html -> answer.html), although it probably isn't wise to do that for certain reasons.


What do I do if I'm stuck?

The puzzles included in the demo encompass a variety of topics, including image steganography, substitution ciphers, and research. Aside from a web browser, the resources linked at the start are all you need.
If you ARE completely stuck, each area has a hint within the page's source code should you need it (although, I would like it if you didn't touch them at all!)


Am I allowed to skip a level?

No.
